# 第一章 先认识两件事：vibe coding 和微信小程序

### 1.1 微信小程序是什么

小程序是一种**不用安装、在微信里打开、用完就走**的应用。

你一定用过：点餐、扫码骑车、查公交、网购，那些"啪一下弹出来"的界面，很多都是小程序。对你（开发者）来说，它有三个好处：

- **用户零门槛**：不用下载 App，微信里搜一下、扫一下码就能用
- **开发门槛低**：比开发一个 App 简单得多，一个人就能做
- **能收款、能获客**：微信里 10 亿用户，分享、扫码、搜索都能带来人

### 1.2 什么是 vibe coding

Vibe coding，直译是"氛围编程"，说人话就是：

> **你用自然语言描述你想要什么，AI 替你写代码，你负责验收和提改进意见。**

就像你请了一个技术外包团队：

- 你说"我要一个待办清单页面，能添加、勾选、删除"
- AI 噼里啪啦把代码写好
- 你运行一下看看，说"删除时加个确认弹窗，别让我误删"
- AI 改好

传统编程像"亲手砌砖"，vibe coding 像"当导演"——你不用会扛摄像机，但你要知道片子要拍成什么样。

### 1.3 工具组合：一个 AI 编程工具 + 微信开发者工具

做小程序需要两个工具，分工明确：

| 工具 | 角色 | 干什么 |
|---|---|---|
| **AI 编程工具**（任选一个） | 大脑（动嘴） | 理解你的需求，写代码、设计方案、查规则、备材料 |
| **微信开发者工具** | 双手（动手） | 微信官方的软件，负责编译代码、手机预览、上传提审 |

为什么必须两个？因为小程序代码最终要被**微信官方**编译、审核、发布，这个通道只认微信官方的工具。AI 工具负责"想"和"写"，微信开发者工具负责"编译"和"上传"。

> 打个比方：AI 是设计师，微信开发者工具是印刷厂。图纸画得再好，最后也得印刷厂来印。

AI 编程工具怎么选？市面上主流的有 Cursor、Claude Code、GitHub Copilot、Windsurf、Trae、通义灵码、CodeBuddy、WorkBuddy 等，对零基础读者来说**都能完成本书的全部工作**，区别只在交互习惯和价格。选型对比见[附录二 B1](附录二-AI编程工具开发小程序速查.md)，拿不定主意就挑一个顺手的开始，工具随时可以换。

### 1.4 哪些事 AI 能做，哪些事必须你本人做

| 事情 | 谁能干 |
|---|---|
| 写代码、设计页面、写云函数、查官方规则、生成文档 | AI |
| 注册小程序、实名认证、人脸识别 | 只能你本人 |
| 扫码授权、签协议、提现账户绑定 | 只能你本人 |
| 在微信开发者工具里点"上传"、在后台点"提交审核" | 只能你本人（也可以让 AI 一步步教你点） |
| 支付密钥、AppSecret 等敏感信息的保管 | 只能你本人，**永远不要发给任何 AI 或第三方** |

记住最后一条：**AI 可以帮你写代码，但你的账号、你的钱、你的身份，只有你能负责。**
