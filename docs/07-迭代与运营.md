# 第七章 阶段六：迭代与运营

### 7.1 看数据：官方三个入口

| 工具 | 在哪 | 看什么 |
|---|---|---|
| 小程序后台「统计」 | mp.weixin.qq.com | 访问趋势、来源、留存、页面详情、用户画像 |
| 「小程序数据助手」小程序 | 微信里搜 | 手机上随时看，可授权给同事 |
| 「We 分析」小程序 | 微信里搜 | 实时数据、交易、体验与性能分析 |

零基础先看四个数：**今天多少人打开、从哪来（搜索/扫码/分享）、下一页还来不来（留存）、哪个页面退出最多**。

### 7.2 收集反馈

- 小程序内放反馈入口（一个"意见反馈"表单，数据进云开发数据库）
- 把用户拉一个微信群，BUG 和新需求第一手收到
- 应用商店/朋友圈的吐槽也要看，那是最真实的用户声音

### 7.3 一次完整迭代的流程

```text
收集问题/需求 → 排优先级（只做最重要的 1-3 件） → 让 AI 改代码
   → 体验版自测 → 提交审核 → 发布 → 看数据验证效果
```

迭代节奏建议：**小步快跑，两周一个小版本**。大版本憋一个月的做法，风险高、反馈慢。

### 7.4 低成本引流

- 小程序码：打印贴在门店、海报、包裹卡上
- 公众号菜单绑定小程序（有公众号的话）
- 朋友圈海报带小程序码
- 企业主体可绑定视频号，直播时挂载小程序（需企业认证的视频号且与小程序同主体，以视频号后台提示为准）
- 起一个好名字：搜索是小程序重要流量入口，名字要含用户会搜的关键词
