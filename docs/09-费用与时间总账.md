# 第九章 费用与时间总账

### 9.1 三条路线的钱（2026 年 10 月标准，以后台实时价格为准）

| | 个人路线 | 个体户路线 | 企业路线 |
|---|---|---|---|
| 认证费 | 30 元/年 | 30 元/年（限时优惠） | 300 元/年 |
| 执照成本 | 0 | 个体户执照（线上办，工本为主） | 公司注册 + 代账（数千元/年） |
| 云开发 | 上线后 19.9 元/月（约 240 元/年） | 同左 | 同左 |
| 支付手续费 | 虚拟支付：安卓 1%/iOS 12% | 商户号：0.6%-1% | 商户号：0.6%-1% |
| 域名（用云开发则为 0） | 0 | 0 | 0 |
| **一年起步合计** | **约 270 元** + 支付手续费 | 约 270 元 + 手续费 + 执照成本 | 约 540 元 + 手续费 + 公司成本 |

**最低可行组合**：个人主体 + 云开发 + 虚拟支付 = 一年不到 300 元，就能拥有一个能收款的小程序。

### 9.2 时间线：从想法到上线

| 周次 | 干什么 |
|---|---|
| 第 1 周 | 想需求、写需求文档、查类目规则；注册 + 提交个人认证（30 元）+ 提交备案 |
| 第 2-3 周 | 等备案的同时：装环境、让 AI 搭项目、做页面 |
| 第 4 周 | 备案下来 → 开通收款（认证第 1 周已办好）→ 部署云函数 → 体验版测试 |
| 第 5 周 | 提审（等 1-7 天）→ 驳回就改 → 发布上线 |

备案是唯一的"不可压缩时间"，其他环节熟练后会越来越快。
