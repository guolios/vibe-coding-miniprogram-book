# 附录一 小程序相关规范速查手册

> 本附录是速查表，细节回正文对应章节。所有数字为 2026 年 10 月官方标准，操作时以 mp.weixin.qq.com 实时显示为准。

## A1 关键规则速查表

| 规则 | 数字/结论 |
|---|---|
| 个人可注册小程序数量 | 5 个（个体户 5 个，企业 50 个） |
| 主体类型 | 提交后**不可变更** |
| 认证费 | 个人 30 元/年；个体户 30 元/年（限时优惠，原价 300）；企业/事业单位/媒体 300 元/年；政府及非营利免费 |
| 认证有效期 | 1 年，到期前 3 个月起分 5 次提醒年审；可申请一次"临时续期 7 天" |
| 备案 | 新小程序**必须备案才能提审**；初审 1-2 个工作日；12381 短信 **24 小时**内核验；管局终审 1-20 个工作日；备案号自动展示在"更多资料页" |
| 备案数量上限 | 个人/个体户 5 个；企业/政府/媒体/其他组织 50 个 |
| 改名 | 每年 2 次免费（1 月 1 日重置）；改名后需更新备案；原名称立即释放 |
| 体验成员 | 个人主体 15 人；非个人 30-90 人 |
| 个人虚拟支付 | 条件：个人 + 工具类目 + 认证 + 备案；月限额 10 万；安卓费率 1%、iOS 12%；结算安卓约 T+3 |
| 微信支付商户号 | 仅经营主体；费率 0.6%-1%；结算一般 T+1；申请免费 |
| 代码审核时长 | 一般 1-7 天（官方口径） |
| 主包/单分包上限 | 2MB |
| 分包总和上限 | 30MB |
| 接口请求 | 必须 HTTPS + 已备案合法域名（云开发免配）；request 类并发上限 10；WebSocket 并发 5；默认超时 60 秒；切后台 5 秒未完成的请求会中断；本地缓存约 10MB |
| 域名白名单细则 | 只能配子域名；不能用 IP/localhost；证书需完整信任链；iOS 不支持自签名证书 |
| 隐私指引 | 后台必填，未声明的接口会被禁用；授权弹窗由微信官方统一提供 |

## A3 服务类目与资质速查（常见）

| 类目方向 | 需要什么 |
|---|---|
| 电商（自营/平台） | 营业执照；平台型可能涉及 EDI 许可证；食品需《食品经营许可证》 |
| 餐饮（点餐交易） | 营业执照 + 《食品经营许可证》 |
| 医疗 | 《医疗机构执业许可证》等，且仅限规定主体 |
| 在线教育（课程培训） | 办学许可/教育部门相关资质（个人不可） |
| 社交/社区 | 增值电信业务许可证等，审核最严 |
| 金融 | 金融业务许可，审核最严 |
| 旅游 | 旅行社业务经营许可证（交易类） |
| 食品经营（备案环节） | 《食品经营许可证》——名称带餐饮属性的，备案时也会被查 |
| 个人主体可做 | 工具、生活服务、菜谱/点评（不交易）、旅游攻略、出行信息、摄影/音乐展示、个人健康记录等 |

> 完整类目库和资质要求：MP 后台「设置」-「基本设置」-「服务类目」，以及官方《小程序开放的服务类目范围》。

## A4 审核驳回 TOP 榜与对策

| 排名 | 驳回原因 | 一句话对策 |
|---|---|---|
| 1 | 类目不符/超主体范围 | 类目和功能一一对应；个人别碰交易 |
| 2 | 用户隐私指引缺失 | 后台填全，勾选实际接口 |
| 3 | 功能与描述不符 | 简介、提审说明、实际功能三统一 |
| 4 | 测试账号进不去 | 附可用测试账号或暂时关闭登录墙 |
| 5 | 页面打不开/白屏 | 真机按审核路径复现，修好再提 |
| 6 | 诱导分享/违规营销 | 删掉"转发才能"类设计 |
| 7 | 名称/简介不规范 | 去极限词、去商业化用语 |
| 8 | 功能过于简单 | 做出完整可用的核心闭环 |

## A5 技术红线速查

- 主包/单个分包 ≤ **2MB**；所有分包合计 ≤ **30MB**（找服务商代开发的才是 20MB）
- 接口必须 **HTTPS**，域名已 ICP 备案且配进后台白名单（云开发免）
- request/uploadFile/downloadFile 并发 ≤ **10**；WebSocket 并发 ≤ **5**
- 默认请求超时 60 秒；小程序切后台 **5 秒**未完成的请求会被中断
- 本地缓存上限约 **10MB**
- 云函数**改后必须重新部署**才生效
- 数据库权限按"最小必要"设置
- 禁止把 AppSecret/AppKey/支付密钥写进前端代码或提交到公开仓库

## A7 上线倒排日历（以注册日为 D0）

```text
D0    注册小程序（10 分钟）
D0-D2 提交个人认证（30 元）→ 一般 1-3 个工作日过审（以通知为准）
D1    提交备案（材料提前备齐）
D3-D4 腾讯初审（1-2 个工作日）→ 盯 12381 短信，24 小时内核验
D4-D25 各省管局终审（1-20 个工作日）→ 备案号下达
D25   开通虚拟支付（如需）→ 建道具 → 发布
D26   上传代码 → 体验版测试 → 提交审核
D26-D33 审核（1-7 天）→ 驳回则改 → 重提
D34   发布上线
（上线后第 15 天：免费云环境到期，转付费 + 开自动续费 + 备份数据）
```
