# 附录二 AI 编程工具开发微信小程序速查

## B1 AI 编程工具能做什么、不能做什么

AI 编程工具的原理都一样：**你用自然语言描述需求，它写代码、改代码、解释代码，你负责验收**。用在小程序开发上，边界如下：

| AI 能做 | AI 不能做（要你自己） |
|---|---|
| 写小程序全部代码（页面、逻辑、云函数） | 注册、实名、人脸识别、扫码授权 |
| 设计数据库结构和集合权限 | 在微信开发者工具里点"编译/预览/上传" |
| 查官方规则、判断类目合规性 | 在 MP 后台点"提交审核/发布" |
| 按你的验收意见反复改代码 | 保管密钥、绑定提现账户、签协议 |
| 生成需求文档、提审材料、合规清单 | 最终拍板"这个功能能不能上线" |
| 读项目文件、批量整理、写 README；装上官方 Skill 后还能直接调用微信开发者工具的能力（部署云函数、订阅消息等） | —— |

**一句话**：AI 是"设计院 + 施工队"，微信官方工具和后台是"发证机关 + 印刷厂"。

### 主流 AI 编程工具选型（零基础够用就好）

| 工具 | 出品方 | 特点 | 费用 | 适合谁 |
|---|---|---|---|---|
| **Cursor** | Cursor 公司 | 专门的 AI 代码编辑器，改代码所见即所得 | 免费档 + 订阅（约 20 美元/月） | 想长期做开发的人 |
| **Claude Code** | Anthropic | 命令行里的 AI 工程师，能自主完成多步任务 | 订阅制 | 愿意接受"没有图形界面"的人 |
| **GitHub Copilot** | GitHub/微软 | 老牌补全 + 对话，生态成熟 | 免费档 + 订阅 | 已经在用 VS Code 的人 |
| **Windsurf** | Codeium 公司 | 类 Cursor 的 AI 编辑器，有免费额度 | 免费档 + 订阅 | 想先免费试试的人 |
| **Trae** | 字节跳动 | 中文界面友好，国内访问稳定 | 免费档 + 订阅 | 英文工具用着别扭的人 |
| **Qoder CN**（原通义灵码） | 阿里云 | Agentic 智能编程平台：IDE + JetBrains 插件，可切换 GLM/DeepSeek/Kimi 等模型 | 有免费额度 + 订阅 | 阿里云生态用户 |
| **CodeBuddy** | 腾讯 | AI 工作台，自然语言派任务 | 有免费额度 | 习惯"对话式派活"的人 |
| **WorkBuddy** | 腾讯 | AI 工作台，任务制 + 资料库 | 有免费额度 | 想让它"读完整本指南再干活"的人 |

**选择建议**：本书的所有操作在任何一款上都能完成，区别只是"怎么跟它说话"。三个务实原则：

1. **先免费后付费**：上面几乎都有免费档，零基础做第一个小程序，免费档通常就够
2. **中文界面优先**：Trae、Qoder CN、CodeBuddy、WorkBuddy 对中文更友好；英文工具也能用中文对话，不必担心
3. **能读文件的优先**：选那种能直接读写你项目文件夹的工具（Cursor、Claude Code、WorkBuddy 都行），"贴代码进去"的效率比"它直接读文件"差一个量级

## B2 高效提示词模板

以下模板可直接复制，把方括号内容换成你的。原则：**一个任务一个目标，说清输入、输出、约束。**

**① 写需求文档**

```text
我想做一个微信小程序，目标用户是[谁]，核心功能是[什么]。
请帮我：
1. 判断这个想法在个人主体下是否可行（对照微信个人主体开放类目）；
2. 写一份 MVP 需求文档：第一版只保留 3 个核心功能，列出页面清单和数据字段；
3. 指出最容易踩的合规坑。
```

**② 初始化项目**

```text
这是小程序项目的需求文档（见附件）。请用原生小程序 + 微信云开发搭建项目：
1. 创建 pages 结构和 app.json 配置；
2. 在 app.js 里写好 wx.cloud.init，环境 ID 先留占位符；
3. 生成每个页面的四个文件（js/json/wxml/wxss）骨架；
4. 写一个 README.md 记录项目约定（页面清单、命名规范），方便后续对话续接。
```

**③ 生成单个页面**

```text
请做[页面名]页面：包含[元素 1、元素 2…]。
交互要求：[比如：点击 X 弹出确认框；下拉刷新；空状态显示提示图]。
数据从云开发数据库的[集合名]读取，字段见 README。
写完告诉我：改了哪些文件、我该在真机上验证什么。
```

**④ 写云函数**

```text
请写一个云函数[函数名]：输入[参数]，实现[逻辑]，返回[结果]。
要求：包含入参校验、错误处理、注释；涉及[用户数据/支付]的操作必须做身份鉴权。
写完逐段解释逻辑给我听，我要确认安全。
```

**⑤ 修 Bug**

```text
在[页面/功能]出现这个问题：[描述现象]。
完整报错信息：[粘贴报错]。
已排除：[比如：已保存、已重新编译]。
请定位原因，给出修改，并解释为什么。
```

**⑥ 合规自查**

```text
对照《微信小程序平台运营规范》和《用户隐私保护指引》要求，
逐项检查我的小程序（文件在项目里）：功能与类目一致性、诱导分享、
隐私接口声明、UGC 审核、名称简介合规性。输出问题清单和修改建议。
```

**⑦ 提审材料**

```text
我要提交审核了。请根据需求文档和实际代码，帮我生成：
1. 功能页面路径列表；2. 审核补充说明（100 字内说清功能）；
3. 提审前自查清单；4. 如有登录功能，提示我准备测试账号。
```

**⑧ 虚拟支付接入（微信官方提示词，直接转发）**

```text
阅读接入指引，并完成个人主体小程序的虚拟支付接入：
https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment/person
最后按文末「部署前检查清单」逐项验收。
```

（另可安装官方 Skill：「小程序虚拟支付：个人接入」。接入后务必人工复核发货逻辑、幂等、对账、退款四项。）

**⑨ 迭代复盘**

```text
这是上周上线后的用户反馈和数据（见附件）。请：
1. 归纳 Top3 问题；2. 评估每个问题的修复成本；3. 给出下一版迭代清单（按性价比排序）。
```

## B3 推荐工作流：每个阶段怎么用 AI

| 阶段 | 派给 AI 的任务 |
|---|---|
| 想需求 | 判断可行性、写需求文档、列合规风险（模板①） |
| 办手续 | 让它把注册/备案/认证的材料清单和步骤整理成"你的专属任务清单"（按主体类型定制），你照着办 |
| 搭环境 | 卡住就问它（比如 Node 装完不识别），把报错整段发给它 |
| 开发 | 初始化（②）→ 逐页面（③）→ 云函数（④）→ 修 Bug（⑤）。每完成一块，让它更新 README |
| 部署 | 生成部署清单和数据库初始化脚本；教你在控制台逐项操作 |
| 接登录 | 生成登录流程和鉴权代码，让它逐段解释逻辑（模板④） |
| 接支付 | 用第七章的官方提示词接入虚拟支付，按「部署前检查清单」验收（模板⑧） |
| 提审 | 生成提审材料和自查清单（⑦）；被拒后把驳回通知发给它出修改方案 |
| 迭代 | 反馈归类、排优先级、改代码（⑨） |
| 维护 | 生成"维护日历"；每次平台规则变化，让它对比新规并给整改清单 |

## B4 上下文与资料库技巧

- **上传本指南**：把这份指南（或相关章节）上传到对话/任务里，它回答问题时会引用规则，减少胡说
- **@ 引用文件**：对话里输入 `@` 加文件名，直接引用项目里的需求文档、README（不同工具的叫法可能不同，也可能是"添加上下文"按钮）
- **固定工作空间**：所有小程序任务选同一个项目文件夹，AI 能持续读写项目文件
- **关键约定落盘**：命名规范、页面清单、环境 ID 等写进项目 README，防上下文丢失
- **敏感信息红线**：AppSecret、AppKey、支付密钥、身份证照片，不要发给任何 AI
- **多任务并行**：手续办理、开发、写文档可以同时开任务并行推进
- **资料库**：把常用文档（本指南、需求文档、平台规则）集中放进工具的知识库/资料库功能（WorkBuddy、CodeBuddy 等都有），任务中可直接检索引用，不用每次重新上传

## B5 微信开发者工具速查

| 操作 | 在哪 |
|---|---|
| 新建/导入项目 | 启动页；导入需填 AppID（不能用测试号） |
| 编译（看效果） | 工具栏「编译」/ Ctrl/Cmd+B |
| 真机预览 | 工具栏「预览」→ 生成二维码 → 微信扫码 |
| 上传代码 | 工具栏「上传」→ 填版本号和备注 |
| 云开发控制台 | 工具栏「云开发」 |
| 部署云函数 | 右键 cloudfunctions 下函数目录 →「创建并部署：所有文件」；含依赖的先在目录里 npm install |
| 看日志 | 云开发控制台 →「云函数」→「日志」，按 requestID 搜 |
| 切环境 | 右键 cloudfunctions →「更多设置」→ 选环境 |

## B6 常见问题

**AI 写的代码跑不起来？**
把报错信息**整段**复制发给它（别转述），让它修。修完让它解释原因，你顺便学一眼。

**对话太久，AI 忘了早期的约定？**
让它读项目里的 README；或者开新任务时重新上传需求文档。重要约定一定要落盘到文件。

**项目太大，一个任务做不完？**
拆成"一个页面一个任务""一个接口一个任务"。任务越小，AI 越准。

**怎么判断 AI 说得对不对？**
涉及规则（费用、时限、资质）的，以本指南附录一和官方后台为准；涉及代码的，以真机跑起来的结果为准。AI 是副驾驶，你才是司机。

## B7 官方可用 Skills 速查

微信小程序团队在 SkillHub（腾讯的 AI Skills 社区）上架了一批**官方 Skill**。装上之后，你的 AI 工具就不只是"写代码的助手"，还能直接调用微信开发者工具的能力——比如替你部署云函数、订阅消息推送、跑编译预览。

Skill 是什么：一段封装好的"专业能力说明书 + 工具"。你把它装进 AI 工具，AI 就学会了这套官方认证的工作方法。安装方式各工具略有差异：有的在设置里搜 Skill 名称一键安装，有的把安装链接发给 AI 让它自己装。

### 核心三件套（零基础最该装的）

| Skill | 地址 | 能干什么 |
|---|---|---|
| **miniprogram-development**（小程序项目开发） | skillhub.cn/skills/tencent-adm/miniprogram-development | 小程序项目开发、微信云开发集成、调试预览 |
| **wechatide-skill**（微信开发者工具 CLI） | skillhub.cn/skills/tencent-adm/wechatide-skill | 替你做开发者工具里的重复操作：编译、预览、上传、云函数部署、消息推送订阅 |
| **miniprogram-virtualpay-person**（虚拟支付：个人接入） | skillhub.cn/skills/tencent-adm/miniprogram-virtualpay-person | 虚拟支付全流程接入：开通激活、道具直购、发货推送、查单、退款、结算费率（该 Skill 需配置 API Key） |

**一键安装**：把下面这段话原样发给你的 AI 工具——

> 请根据 https://skillhub.cn/install/skillhub.md，安装 @tencent-adm/miniprogram-virtualpay-person、@tencent-adm/miniprogram-development、@tencent-adm/wechatide-skill。

它会自动完成 SkillHub CLI 的安装和三个 Skill 的下载加载。装完让它复述一遍每个 Skill 的用途，确认加载成功再用。

### 进阶：小程序 AI 开发模式系列（ tencent-adm ）

这套 Skill 面向"把自己的小程序能力封装成 AI 可调用的接口"，属进阶玩法，第一版用不上，了解即可：

| Skill | 能干什么 |
|---|---|
| wxa-create-mp-skill | 在现有项目里新建一个自定义 AI Skill（自动串起"生成 + 校验"两步） |
| wxa-skills-generate | 分析你的项目源码，生成"原子接口 + 原子组件"代码分包 |
| wxa-skills-validate | 依托开发者工具真机校验上一步的产物，跑不通会自动修 |

> 两个前置说明：① 官方的"评测 Skills"正在升级，暂不开放；② 校验 Skill 依赖 Nightly 版微信开发者工具，且要先去「设置」-「安全设置」打开**服务端口**，项目还需在 MP 后台「基础功能」-「AI 能力」申请通过"开发模式"。

### 云开发相关（腾讯云 CloudBase 团队）

在 SkillHub 搜 `cloudbase`，找到 CloudBase AI Toolkit 相关 Skill，覆盖微信云开发项目的开发、构建、部署、调试。做重后端时可以考虑。

### 三条使用提醒

1. **先装三件套就够**：其他 Skill 等真正需要时再装，装太多 AI 会"选择困难"。
2. **Nightly 版开发者工具**：虚拟支付相关能力需要 Nightly 版微信开发者工具（版本 ≥ 2.02.2608312），它的菜单里有「复制 Skill 安装提示词」，一键复制安装指令。
3. **以官方当期说明为准**：Skill 的功能、依赖、版本要求迭代很快，安装前看一眼 SkillHub 页面上的最新说明。

## 写在最后

这本指南覆盖的是一条"普通人的小程序之路"：不需要学编程，不需要组建团队，一年不到 300 块钱，就能把自己的想法变成微信里跑着的产品。

你会发现，整个流程里最稀缺的不是技术，而是两样东西：**想清楚做什么的耐心**，和**被驳回后改完再提的勇气**。

这两样，AI 都给不了你。

祝上线顺利。
